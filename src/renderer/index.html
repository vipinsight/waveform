      AI Polish
      
          
      
            Optional. Speech comes out the way it was spoken — with the ums, the repeated
            words, the missing commas. Polish hands that text to an AI to tidy before it
            lands. That AI can be a model on this Mac, which sends nothing anywhere, or a
            hosted one, which is the only part of Waveform that sends anything off
            this Mac; the transcription itself never does.

      Model on this Mac
      
            
      
              The model runs here, so it has to be downloaded before it can be used —
              press a row marked with  to fetch one. These are small models: they
              fix filler, punctuation and capitals well, and a hosted model still reads a
              long or unusual passage better.
            
      
            
      
          
      

          
      What to tell the AI
      
          
      
            These steer how text is tidied. Waveform holds the reply to a rewrite of that
            same text, so a reply that answers it or wanders off is dropped and your
            original is kept.
