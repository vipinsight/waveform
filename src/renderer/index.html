Setup

Enable macOS permissions and install a speech model to dictate in any app.

  1. Microphone Audio stays on this Mac.
  2. Speech model Runs offline on this Mac.
  3. Input Monitoring Detects your dictation shortcut in other apps.
  4. Accessibility Allows Waveform to insert text in other apps.

macOS ties these to the app's signature. If a permission looks granted but is refused, remove Waveform from the list and add it again.
