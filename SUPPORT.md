# Getting help

Start with [Using Waveform](docs/using.md), [Building](docs/building.md), and
[Models](docs/models.md). Check existing issues before opening a new one.

- **Bug:** use the bug report template with the app version, macOS version,
  Mac chip, engine/model, permissions, and steps to reproduce.
- **Feature:** explain the problem and any workaround in the feature template.
- **Question:** open an issue describing what you tried and where you got stuck.
- **Security:** follow [SECURITY.md](SECURITY.md); do not disclose details publicly.

Logs can contain transcribed text. Remove private content and API keys before
sharing. Support is provided by volunteers without a guaranteed response time.
